# ポーランド語 日常会話アプリ 設計書

## 目的

ポーランド語初心者(知識ゼロ)の日本人ユーザーが、ポーランド人の家族と日常会話できるようになるための個人学習用Webアプリ。試験対策ではなく、フレーズの暗記が学習の中心。文法解説は最小限。

## スコープ判断

新規プロジェクト(既存NOKENアプリとは別の独立プロジェクト)。アーキテクチャパスとして設計する。

## 配置場所

`C:\Users\Lenovo\Desktop\polish-app`(NOKENアプリとは独立した兄弟フォルダ)

## 技術スタック

- プレーンHTML/CSS/JavaScript。サーバー・DB不要。
- データは `data/content.js` に `const POLISH_DATA = {...}` というJSグローバル変数として定義し、`<script>` タグで読み込む。
  - 理由: `file://` でindex.htmlを直接ダブルクリックで開いても動作させるため(fetchによるJSON読み込みはCORSでブロックされる)。NOKENアプリと同じパターンを踏襲。
- レスポンシブCSS(PC・スマホ両対応)。

## ファイル構成

```
polish-app/
├── index.html
├── css/
│   └── style.css       # ピンク×水色テーマ、カード型UI、レスポンシブ
├── js/
│   └── app.js           # 画面描画・遷移・クイズロジック
└── data/
    └── content.js        # alphabet, digraphs, categories[]
```

## データ構造

指示書のJSON構造を踏襲:

```js
const POLISH_DATA = {
  alphabet: [ { letter, reading, note } ],
  digraphs: [ { letters, reading } ],
  categories: [
    {
      id, title,
      phrases: [ { pl, reading, ja, note } ]
    }
  ]
};
```

- `reading` はカタカナ発音目安。ユーザーからのフィードバックにより、**発音の分かりやすさを重視**する(下記「発音表示の方針」参照)。
- 新しいカテゴリ・フレーズは `categories` 配列への追加のみで画面に自動反映される。UIコードの変更は不要。

## 発音表示の方針(追加要件)

ユーザーは発音の難しさを懸念している。カタカナ読みを控えめな補助情報として隠すのではなく、フレーズカードの中でポーランド語表記の直下に常に見える形でカタカナ読みを表示する(ルビ的な扱い)。クイズ画面でも正誤表示時にカタカナ読みを併記し、発音を毎回思い出せるようにする。

## 画面構成

NOKENアプリと同様、1ページ内で `.screen` クラスの表示切替によって画面遷移する(SPA的構成、ルーティングライブラリ不要)。

1. **トップ画面**: 「文字」カード + 8カテゴリカードをカード型で一覧表示
2. **文字学習画面**: 独自文字(ą, ć, ę, ł, ń, ó, ś, ź, ż)+特殊な組み合わせ(cz, sz, rz, dz, dź, dż)を一覧表示。カタカナ発音目安と説明付き
3. **カテゴリ詳細画面**: 選択したカテゴリのフレーズをカード一覧表示。ポーランド語+カタカナ読みは常時表示、タップで日本語訳・メモの表示/非表示を切替
4. **クイズ画面**: カテゴリ選択→出題方向(日本語→ポーランド語 / ポーランド語→日本語)を選択→4択の選択式クイズ→スコア表示
   - 誤答選択肢: 同カテゴリ内の他フレーズからランダムに3つ抽出。カテゴリ内フレーズが4未満の場合は他カテゴリから補完
   - 正誤表示時にカタカナ読みも併記

## 初期コンテンツ

以下8カテゴリ、各カテゴリ約10フレーズを開発者(Claude)が作成する:

1. 挨拶・別れ
2. 相槌・つなぎ言葉
3. 気持ち・体調を伝える
4. 質問する・聞き返す
5. お願い・感謝・謝罪
6. 簡単な返事(はい/いいえ/たぶん/わからない)
7. 家族の会話でよく出る一言(おやすみ、いってきます、ただいま、など)
8. 数字(0〜100程度+時間・値段・年齢などでの使い方)

文字パート(alphabet/digraphs)も指示書のサンプルをベースに完成させる。

## デザイン方針

- メインカラー: ピンク×水色。NOKENアプリ(赤×金)とは配色が衝突しないことを確認済み。
- カード型UI、明るく学習ハードルの低い雰囲気。

## 拡張性

- コンテンツ(文字・カテゴリ・フレーズ)はすべて `data/content.js` に集約し、コードと分離。
- 新カテゴリ追加・既存フレーズ修正は `data/content.js` の該当箇所の変更のみで完結する設計とする。

## テスト・検証方針

Claude Browser (Preview) で以下を確認する:

- トップ画面からの各画面遷移
- カテゴリ詳細画面でのカード開閉(発音・メモの表示切替)
- 文字学習画面の一覧表示
- クイズの出題→回答→採点フローの動作
- レスポンシブ(スマホ幅)での崩れがないこと
